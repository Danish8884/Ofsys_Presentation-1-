# 📊 Sales Analytics Dashboard

An interactive **Sales Analytics Dashboard built in Microsoft Excel** to track sales performance, customer activity, product performance, regional performance, profitability, and order trends.

## 🎯 Project Objective

The main objective of this project is to transform raw sales data into meaningful business insights using **Pivot Tables, Pivot Charts, Slicers, KPIs, and interactive dashboard visualizations**.

## 📌 Key KPIs

- 💰 Total Revenue — **1,443,357.97**
- 📦 Total Quantity Sold — **5,314**
- 🛒 Total Orders — **500**
- 💵 Average Order Value — **2,886.72**
- 👥 Total Customers — **206**

## 🎛️ Interactive Filters

- **Month**
- **Region**
- **Item Category**

## 📈 Dashboard Analysis

The dashboard provides analysis of:

- Monthly Sales Trend
- Sales by Region
- Profit by Region
- Top 5 Customers by Revenue
- Sales vs Cost by Product
- Sales by Item Category
- Quantity Sold by Product
- Orders Over Time

## 🗂️ Dataset

The dataset contains **500 sales orders** with information such as:

`Order ID` • `Order Date` • `Customer ID` • `Customer Name` • `Product ID` • `Product Name` • `Item Category` • `Region` • `Quantity Sold` • `Unit Price` • `Cost Amount` • `Sales Amount` • `Profit` • `Quarter` • `Month`

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Data Cleaning
- Data Visualization

## 💡 Business Insights

This dashboard helps identify:

- Top-performing regions and products
- High-value customers
- Monthly sales and order trends
- Profitable product categories
- Sales versus cost performance
- Opportunities for business growth
